# 네온 배달부

네온 도시의 앵커 포트를 와이어로 연결하며 제한 시간 안에 음식을 배달하는 웹 기반 스윙 액션 게임입니다.

설치와 회원가입 없이 브라우저에서 바로 플레이할 수 있습니다.

## 플레이 방법

- 첫 입력: 옥상에서 점프
- 클릭 또는 터치 유지: 앵커 포트에 와이어 연결
- 입력 해제: 현재 진행 방향으로 와이어 해제
- `Space`: Pulse Boost 사용
- `R`: 빠른 재시작

## 게임 목표

- 총 10개의 배달 링을 통과해 주문을 완료합니다.
- 주문별 제한 시간은 15초입니다.
- 정시 배달과 지연 배달 결과에 따라 별점을 획득합니다.
- 부스트 게이트를 통과하면 Pulse Boost를 충전할 수 있습니다.
- 드론과 추락을 피하고 2,500m 지점의 도착 스테이션까지 이동해야 합니다.

## 주요 특징

- 캐릭터 중심의 와이어 스윙 액션
- 무작위 음식 주문 10개
- 정시·지연·실패를 반영하는 5점 별점 시스템
- 직선형 및 상하 이동형 드론
- 스프링 세이브 발판과 Pulse Boost
- 문 개폐와 캐릭터 입장으로 이어지는 완주 연출
- Web Audio API 기반 효과음과 152 BPM 신스 BGM
- 별도 라이브러리와 외부 API가 필요 없는 단일 HTML 게임

## 실행

`index.html`을 브라우저에서 열면 실행됩니다.

로컬 서버를 사용할 경우:

```bash
python3 -m http.server 8000
```

이후 `http://localhost:8000`으로 접속합니다.

## 개발용 미리보기

- 드론: `index.html?preview=drones`
- 완주 연출: `index.html?preview=finish`
